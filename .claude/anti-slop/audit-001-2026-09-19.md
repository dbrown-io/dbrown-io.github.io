# antislop audit 001

Date: 2026-09-19
Scope: index, about, experience, services, photography

antislop: skills at 7437352, rules R-01 to R-38

Filed under `.claude/` rather than `anti-slop/` as the skill specifies:
this repo is served by GitHub Pages, and a top-level `anti-slop/` folder
would publish this audit at a public URL. Jekyll skips dotfiles.

## Findings

Priority follows the rule tier: Hard Gate HIGH, Purpose-Gate MEDIUM.

### HIGH

1. R-32 Keyboard accessibility. No focus styles anywhere: `:focus` appears
   0 times in styles.css. Nothing sets `outline: none`, so the browser
   default ring survives and the site is operable, but pill-shaped
   controls (nav tabs, contact button, both at `border-radius: 100px`)
   get a rectangular default ring that reads as a rendering fault. The
   rule wants a deliberate, clearly visible indicator.

2. R-37 Design direction required. No DESIGN.md and no written direction.
   The site does have an identity (paper ground, tape swatches, a Caveat
   signature) but nowhere states it, so every Purpose-Gate rule below
   fails for the same reason: the intent exists only in the CSS.

3. R-02 Copywriting. One em dash, photography.html, in the People Shoots
   paragraph. Introduced by Claude, not by David.

### MEDIUM

4. R-07 Background. The dot grid is the exact pattern the rule names
   ("dot patterns as a background"). Defensible as part of the paper
   identity, but the reason is not written down.

5. R-06 Typography. Inter and Space Grotesk are both named in the rule as
   AI-default picks. Two uppercase letter-spaced label styles
   ("POPULAR RIGHT NOW", "DOG SHOOTS") match the tracked-label pattern.

6. R-19 Animations. `fadeUp` is applied to 14 selectors, which is the
   "every element using Fade Up" case. No stated UX purpose.

7. R-12 Shadow. 14 box-shadow declarations, nearly all the same two-layer
   shadow, so it marks no elevation hierarchy: everything floats equally.

8. R-14 Feature cards. The six service tickets share size, icon
   treatment, padding and layout, with no variation reflecting which
   service matters most.

9. R-04 Icons. Lucide-style thin rounded strokes throughout. Most map
   well (paw, monitor, graduation cap); two do not: a map pin for
   "Garden & Outdoor Jobs" and a 2x2 grid for "3D Printing".

10. R-08 Button arrows. Four CTAs carry a right arrow with no stated
    purpose.

## Passing

Verified, not assumed:

- R-25 Contrast. Every text pair meets AA. `--ink-dim` 6.57:1 on card,
  `--ink-faint` 4.96:1 on the placeholder surface, route link 5.28:1,
  button text 12.52:1.
- R-03 Mobile. No horizontal overflow on any page at 390px
  (scrollWidth == clientWidth on all five).
- R-24 Navigation. All four destinations exist.
- R-26 Interactive elements. No dead controls; the only non-links are the
  details/summary accordions, which work.
- R-17, R-18, R-36 No invented numbers, testimonials or claims. The
  20K-30K figure is David's own work.
- R-38 Placeholders labelled honestly ("COMING SOON", "SHOT BOOKED").

## Note

Findings 4 to 10 are Purpose-Gate: the technique is allowed once the
reason is written. Fixing finding 2 discharges most of them, because the
identity they serve is real but undocumented.
